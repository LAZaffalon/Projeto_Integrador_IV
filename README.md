
Projeto a ser desenvolvido por alunos da Univesp.

Tema: Desenvolver análise de dados em escala utilizando algum conjunto de dados existentes ou capturados por IoT e aprendizagem de máquina. Preparar uma interface para visualização dos resultados.

Os datasets das turmas do 2º e 5º anos foram pre-processados, etapa necessária antes da análise exploratória dos dados. Os datasets para trabalhar com a parte da interface para visualização estão na pasta dataset_clear, nomeados como turma_2ano.csv e turma_5ano.csv.

A aplicação Streamlit está conectada a um banco de dados SQLite local, que é alimentado automaticamente a partir dos arquivos tratados da pasta dataset_clear. Dessa forma, os dados são organizados em tabela e utilizados pela interface para exibir métricas e gráficos da performance escolar.
